Diseño WEB

El diseño web es el proceso de crear y organizar los elementos de una página web. Utiliza diferentes tecnologías para establecer la estructura, apariencia y funcionamiento de un sitio web.

HTML es un lenguaje de marcado utilizado para crear la estructura de una página web. Mediante etiquetas permite agregar títulos, párrafos, imágenes, enlaces y otros elementos que forman parte del contenido.

La experiencia de usuario busca facilitar la navegación dentro de una página web. Una estructura organizada, botones claros y una distribución adecuada de la información permiten que el usuario encuentre fácilmente lo que necesita.
