Tecnologías del Diseño WEB

CSS es un lenguaje utilizado para definir la apariencia visual de una página web. Permite modificar colores, tamaños, fuentes, espacios y diferentes características de los elementos que forman parte de un documento HTML.

El diseño responsivo permite que una página web se adapte a diferentes dispositivos y tamaños de pantalla. De esta manera, el contenido puede visualizarse correctamente en computadoras, tablets y teléfonos móviles.

Los hipervínculos permiten conectar diferentes páginas o documentos mediante la etiqueta a de HTML. El atributo href indica la ubicación de la página o recurso al que se desea acceder.
